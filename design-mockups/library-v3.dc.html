How content flows

Every path a file can take from creation to a live post. Each node names the code that owns it.
1 · Sources
Upload
Drag files in. Checksum + perceptual hash run before the row is written, so a duplicate is caught at the door.
personal-asset-upload
AI Studio generation
Finishing a generation writes the Library row itself — you never “save to Library”.
sync_personal_asset_from_post()
Video clip
A long video is cut into shorts; saving a clip reuses the upload pipeline so it gets the same checks.
clipLibraryActions.saveClipToLibrary
Post-linked record
A text-only post still gets a row, so the Library is a complete history. It has no file and never offers Publish.
source = 'post'
2 · Library
One collection
Source is provenance, not a separate silo. Everything lands in the same grid and is filtered, never segregated.
Auto-enrichment
Tags, alt text and a transcript are generated in the background. The card shimmers until they land.
Lifecycle
Versions supersede rather than overwrite. Archive hides. Delete is a recoverable trash, not a destruction.
3 · The gate
Is there a file the publisher can fetch?
The publisher resolves media one way only: post → generation. An asset without that link publishes an empty post. The card says so before you click, not fourteen seconds after.
publish-post/index.ts
Does a connected account accept it?
YouTube and TikTok take video. LinkedIn takes image, video or text. A still with no image-capable account connected has nowhere to go — shown as a warning, not a failed publish.
publish_providers
