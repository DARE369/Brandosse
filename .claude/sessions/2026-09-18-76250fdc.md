- **B found a live defect.** `scripts/security/scheduled-publish-probe.mjs`
  seeds a due post with no media and watches the cron job. Result: the post
  never left `scheduled`.

**Hit — the finding, which is the important part of this pass.**
`process-scheduled-posts` has been failing **every minute since 2026-09-10**:

```
ERROR: function net.http_post(url => text, headers => jsonb, body => text)
       does not exist
CONTEXT: PL/pgSQL function dispatch_scheduled_post(uuid,uuid,uuid,uuid) line 32
```

pg_net's `body` is jsonb; `20260910130000:105` casts it `::text`. The exception
unwinds the whole cron transaction, including the UPDATE that marked the post
`publishing`, so the post returns to `scheduled` and is retried forever. It is
never failed, because `fail_undispatchable_scheduled_posts()` only fails posts
with no matching ACTIVE account. **Nothing anywhere surfaced it.**

It is a REGRESSION: `20260710160000` fixed this exact error in July, and the
September rewrite (adding the X-Invoke-Secret header) reintroduced it. Broken
and working differ by one cast.

Two probe lessons: my first version reported "never left scheduled" without ever
printing the status it observed — fixed to log every transition. And the cron
error was only visible through `get_cron_job_status()`, not from the post row.

**Resolved.** `20260918120000_dispatch_body_is_jsonb.sql` written, with a
post-condition that calls the real dispatch inside a rolled-back subtransaction
(pg_net queues by INSERT, so the rollback discards the request — nothing is
sent). Guard `check-pgnet-body-type.cjs` scans at paren depth: its first version
had false positives on the *correct* migrations because the last value inside
`jsonb_build_object` is itself `p_organization_id::text`. Now silent on good
code and catches the real regression.

**Open.** The migration is NOT yet applied — waiting on the founder. Until then
scheduled publishing is still dead. After applying, re-run
`node scripts/security/scheduled-publish-probe.mjs`; expect PASS failing at
media validation.
